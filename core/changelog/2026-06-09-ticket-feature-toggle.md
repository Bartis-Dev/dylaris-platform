title: Tickets are now a per-platform feature toggle
---
The ticket system can now be turned on or off platform-wide from Settings → Features. Default is **off** — fresh installs no longer expose the Tickets module by default.

Admins flipping it on will see the Tickets module reappear in the top nav and the "Via tickets" tab return to the server sidebar for support users.
